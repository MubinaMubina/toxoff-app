# Manrope

The app bundles static 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold),
and 800 (ExtraBold) weights of Manrope 4.504. This matches the Manrope version
served by https://toxoff.app/assets/fonts/manrope-latin.woff2.

Source: https://github.com/google/fonts/tree/main/ofl/manrope
Variable source: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
License: [SIL Open Font License 1.1](OFL-Manrope.txt).

The static files were generated with FontTools 4.57.0 using
`fontTools.varLib.instancer.instantiateVariableFont` at each `wght` value,
with `updateFontNames=True`. Each face has a distinct `Manrope-<Weight>` family
and PostScript name for native runtime registration. The full source glyph
coverage is retained; no network font request is needed when the app runs.
